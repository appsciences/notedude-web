2026-10-11 · release journal

plain text grew a few superpowers.

Full Markdown rendering, portable backups, and a more deliberate keyboard map.

Headings and lists arrived on September 30. This release extends the reading view to bold, italic, strikethrough, inline code, links, fenced code, quotes, rules, task lists, and tables. Press m or Shift+Command+M to inspect the raw Markdown and press it again to render. The text remains the source.

Full rendering has an entitlement hook, currently enabled for everyone while billing is being developed. Inline formatting shortcuts are a separate backlog item; rendering Markdown and adding a shortcut for every style are different pieces of work.

Shift+E exports all notes to a versioned JSON backup. Shift+I imports a backup. It’s a practical escape hatch and an easy way to keep a copy outside the app.

The keyboard map also got clearer. i joins e as the edit key. Command+C copies the selected note when no text is selected. dd opens a confirmation before deletion, and Shift+D opens the donate page. Pasted nested lists now arrive as Markdown the renderer understands.
