## reference
the entire keyboard map.
~/notes  ·  navigation
/
focus search
j / k
next / previous note
gg / G
jump to first / last note
Esc
leave search
~/notes  ·  editing
⌘+N
new note
⌘+D
delete current note
⌘+E
toggle todo checkbox
⌘+P
pin / unpin note
⌘+]
indent list item
⌘+[
outdent list item
~/notes  ·  tags & filters
#
start a tag (autocomplete kicks in)
⌘+T
add tag to current note
⌘+⇧+F
filter library by tag
~/notes  ·  window
⌘+\
toggle sidebar
⌘+,
settings
?
show this cheatsheet, anywhere
